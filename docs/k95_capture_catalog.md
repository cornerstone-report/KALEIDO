# K95 Capture Catalog

No K95 screenshots or video were included in `Original/`. This catalog reserves
the research set required for visual alignment. Captures are private research
fixtures; they are not bundled, displayed, or redistributed by KALEIDO.

- [Screensavers Planet listing](https://www.screensaversplanet.com/es/screensavers/kaleidoscope-95-1475/): currently advertises three screenshots. Treat them as viewing references only; do not import them into this repository.

## Capture protocol

Run only in an isolated legacy environment owned by the project. Record original
settings separately from the KALEIDO repository. Do not upload binaries,
registration material, screenshots, or extracted assets to the public project.
