# Research fixtures

Private reconstruction notes live here. They are not presets, UI copy, or
shipped strings. Historical product names stay out of `src/`.

Extracted favorite records from the 1990s binary are research-only. Map their
*behaviors* onto original KALEIDO controls:

- symmetry → fold order (petal scallop count)
- spin → angular velocity
- trail length → stamp generations
- width / splitting → ring span and skip walk
- color rotation / bands → palette speed and band count

Do not import the raw favorite names or serialized rows into the public app.
